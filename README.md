# دفء | Dafa Studio

Interior design & furniture studio website — static multi-page site (HTML/CSS/JS, no build step required).

## Pages
- `index.html` — Home
- `about.html` — About / Who We Are
- `banks.html` — Bank interior design
- `office.html` — Office design
- `indoor.html` — Indoor / home furniture
- `outdoor.html` — Outdoor furniture
- `schools.html` — School furniture

## Running locally
Just open `index.html` in a browser — no server or build step needed.

## Deploying with GitHub Pages
This repo is ready for GitHub Pages as-is:
1. Push the repo to GitHub (see commands below).
2. Go to the repo's **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then **Save**.
5. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
